# Exponentia

Welcome to **Exponentia** — a fantasy-adventure math game designed to help you master the 8 Laws of Exponents!

## Project Info

This project is built using:
- **Vite** (Build Tool)
- **React** (UI Library)
- **TypeScript** (Language)
- **Tailwind CSS** (Styling)
- **shadcn-ui** (Component Library)
- **Vite PWA** (Offline capabilities)

## Getting Started

To get started with development locally:

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Production Build

To build the application for production:

```bash
npm run build
```

This will output the optimized build to the `dist` directory, ready to be served by any static file host.
