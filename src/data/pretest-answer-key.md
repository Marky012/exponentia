# Quick Testing Guide

## Pre-Test Answer Patterns (Questions are randomized!)
- **Product of Powers**: A, A, B, A, B (look at question text)
- **Quotient of Powers**: A, A, A, B, A
- **Power of a Power**: B, B, B, B, B (always B!)
- **Zero Exponent**: B, B, B, B, B (always B = 1!)
- **Negative Exponent**: B, B, B, B, B (always B = reciprocal!)
- **Power of Product**: A, A, C, D, A
- **Power of Quotient**: D, C, C, D, C
- **Identity Exponent**: A, A, A, A, A (always A!)

## Key Rules to Remember:
1. **Product**: Add exponents (aᵐ × aⁿ = aᵐ⁺ⁿ)
2. **Quotient**: Subtract exponents (aᵐ ÷ aⁿ = aᵐ⁻ⁿ)
3. **Power of Power**: Multiply exponents ((aᵐ)ⁿ = aᵐⁿ)
4. **Zero**: Any number⁰ = 1
5. **Negative**: a⁻ⁿ = 1/aⁿ
6. **Product Power**: (ab)ⁿ = aⁿbⁿ
7. **Quotient Power**: (a/b)ⁿ = aⁿ/bⁿ
8. **Identity**: a¹ = a
