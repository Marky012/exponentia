## Quick Reference by Law

- **Product of Powers**: Add exponents → A, A, B, A, B
- **Quotient of Powers**: Subtract exponents → A, A, A, B, A
- **Power of a Power**: Multiply exponents → B, B, B, B, B
- **Zero Exponent**: Always 1 → B, B, B, B, B
- **Negative Exponent**: Flip to fraction → B, B, B, B, B
- **Power of Product**: Distribute exponent → A, A, C, D, A
- **Power of Quotient**: Distribute to num/denom → D, C, C, D, C
- **Identity Exponent**: Same number → A, A, A, A, A

**Note**: Questions are randomized on each attempt, so the order will vary!
